## 이 챕터에서 다루는 내용

- **MCAP** 으로 raw 데이터 기록, **HDF5** 로 학습용 변환
- 녹화·라벨링·정합 검증 절차
- 데이터셋 디렉토리 구조 및 메타데이터 표준

## 파이프라인 개요

```
ROS2 토픽 ──▶ MCAP Recorder ──▶ *.mcap (raw, 원본 보존)
                                  │
                                  ▼
                          MCAP → HDF5 변환기 ──▶ *.hdf5 (학습용)
```

원본은 MCAP 으로 보존하고, 학습 단계는 항상 HDF5 를 입력으로 사용합니다.
새로운 모델에서 추가 채널이 필요해질 경우 MCAP 으로부터 재변환합니다.
