## 베이스 스테이션 배치

- 최소 2개, 권장 4개 (대각선 배치, 약 2~2.5m 높이, 추적 영역을 안쪽으로 향하게)
- 베이스 간 시야가 서로 직접 보이지 않도록 함 (Lighthouse 2.0 채널 충돌 회피)

## 트래커 페어링

1. SteamVR 실행 후 **장치 → 페어링** 메뉴 진입
2. 트래커 전원 ON → LED 청색 깜빡임 상태에서 페어링
3. 페어링 완료 후 트래커 역할(Role) 지정:
   - 좌 손목 트래커
   - 우 손목 트래커
   - 허리 트래커 (로봇 base_footprint 기준)

## 부착 위치

| 트래커 | 부착 위치 | 용도 |
| --- | --- | --- |
| Left Wrist | 작업자 좌 손목 | 좌 EE 목표 |
| Right Wrist | 작업자 우 손목 | 우 EE 목표 |
| Waist | 작업자 허리 | RBY1 `base_footprint` 와 고정 변환 |

## 동작 점검

- SteamVR Status 창에서 세 트래커 모두 녹색 상태 확인
- 추적 영역 경계에서 jitter / dropout 발생 시 베이스 위치 재조정

> 본 시스템은 별도의 **트래커-로봇 캘리브레이션 절차가 없습니다**. 허리 트래커가 곧 로봇 베이스 기준점이 되며, 변환은 설정 파일의 고정 오프셋으로 처리됩니다. 자세한 동작 원리는 [원격제어 → 트래커-로봇 좌표 변환](../../teleoperation/tracker-frame-transform/) 참고.
