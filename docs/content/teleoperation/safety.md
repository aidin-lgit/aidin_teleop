## 작업 전 점검

- 로봇 가동 범위 내 사람·장애물 제거
- E-Stop 버튼 위치 및 동작 점검
- 손가락/케이블 끼임 위험 영역 식별

## E-Stop

- 하드웨어 E-Stop: RBY1 본체 / 운영 책상 / 작업자 발치(풋스위치, 권장)
- 소프트웨어 비활성화 (Disengage) 는 E-Stop 을 **대체하지 않음**
- E-Stop 트리거 시 텔레옵 노드는 자동 disengage 상태로 진입

## 비상 시 절차

1. E-Stop 트리거
2. 로봇 정지 및 잔류 모션 확인
3. 텔레옵 노드 종료 (`Ctrl+C`)
4. 원인 파악 후 안전이 확보된 상태에서만 재기동

## 일상적 권장 사항

- 단독 작업 금지, 감독자 1인 이상 배석
- 데이터 수집 세션은 최대 90분 단위로 휴식 권장 (작업자 피로 누적은 데이터 품질 저하의 주된 원인)
