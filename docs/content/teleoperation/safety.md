## 작업 전 점검

- 로봇 가동 범위 내 사람·장애물 제거
- E-Stop 버튼 위치 및 동작 점검

## E-Stop

본 시스템의 E-Stop 은 동작 시점에 따라 두 가지 유형으로 구분됩니다.

- **상시 E-Stop** — 원격제어 활성화 여부와 무관하게 항상 동작하는 하드웨어 차단 수단 (몸체 버튼 / 리모컨)
- **원격 제어시 E-Stop** — 원격제어 세션 중 키보드·발판으로 트리거하는 소프트웨어 차단 수단

### 상시 E-Stop

#### 하드웨어 E-Stop (몸체 버튼)

RBY1 몸체에 부착된 **비상정지 버튼**을 누르면 로봇 전원이 즉시 차단됩니다.

![RBY1 하드웨어 E-Stop 버튼](/images/rby1_estop.jpg?width=200px)

#### 원격 E-Stop (리모컨)

작업자와 떨어진 위치에서도 즉시 전원을 차단할 수 있도록 무선 리모컨이 제공됩니다. 두 가지 동작을 지원합니다.

| 버튼 | 동작 |
| --- | --- |
| **1번 버튼** | 언제든지 누르면 즉시 로봇 전원 차단 |
| **2번 버튼** | 차단된 전원을 복구 (안전 확인 후 사용) |

![RBY1 원격 E-Stop 리모컨](/images/rby1_remote.jpg?width=300px)


### 원격 제어시 E-Stop

원격제어 세션이 실행 중일 때는 작업자가 키보드 또는 발판 스위치로 즉시 정지를 트리거할 수 있습니다.

| 트리거 | 매핑 |
| --- | --- |
| 키보드 | `b` 키 (한글 IME: `ㅠ`) |
| 발판 스위치 | 가운데 페달 |

트리거되면 `aidin_rby1_vive_teleop` 노드가 `emergency_stop` 서비스를 호출하여 **RBY1 UPC 의 제어기 노드를 종료**합니다. 동시에 녹화 세션도 닫히고 원격제어 노드 자체도 shutdown 됩니다.

상시 E-Stop(하드웨어/리모컨) 과 달리 전원 자체를 끊는 것이 아니므로, 안전이 확보되지 않은 상황에서는 상시 E-Stop 을 함께 사용하세요. 상태 머신과 키 매핑 상세는 [`aidin_rby1_vive_teleop`](https://github.com/aidin-lgit/aidin_rby1_vive_teleop) README 참고.

## 비상 시 절차

1. E-Stop 트리거
2. 로봇 정지 및 잔류 모션 확인
3. 텔레옵 노드 종료 (`Ctrl+C`)
4. 원인 파악 후 homing 초기화 자세로의 안전 확보한 다음에 재기동
