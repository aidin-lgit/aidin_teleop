## 텔레옵 활성화 / 비활성화

- 활성화: 운영 GUI 의 `Engage` 버튼 또는 키보드 `E` 키
- 비활성화: `Disengage` 버튼 또는 키보드 `D` 키
- 비활성화 시 로봇은 마지막 자세에서 hold

## 작업 자세

- 작업자는 작업 영역을 향한 자세로 정렬 (허리 트래커 정면이 로봇 정면과 일치하도록)
- 처음에는 양손을 가슴 앞으로 모은 중립 자세에서 활성화 권장

## 손가락 매핑

- MANUS 로부터의 손가락 관절 → AIDIN Hand 관절로 리타게팅
- 매핑 파일: `aidin_rby1_teleop/config/retarget_left.yaml`, `retarget_right.yaml`

## 시야

- Meta Quest 영상은 양안 stereo 로 송신, 작업자는 1인칭 시점으로 매니퓰레이션 수행
- 영상 지연이 크다고 느껴지면 Wi-Fi 채널/대역 점검 또는 USB 유선으로 전환

## 운영 팁

- 추적 영역 경계 근처에서 작업 시 트래커 dropout 주의
- 글로브 캘리브레이션이 무너졌다고 느껴지면 즉시 비활성화 후 재캘리브레이션
- 한 에피소드는 5~30초 정도가 후속 학습에 다루기 쉬움 (긴 시퀀스는 청크 분할 고려)
