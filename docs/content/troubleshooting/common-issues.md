## VIVE Tracker 가 회색/적색으로 표시됨

- **원인 후보**: Lighthouse 시야 가림, 채널 충돌, 배터리 부족
- **조치**: 베이스 위치 재조정, 채널 재설정, 배터리 교체

## 텔레옵이 활성화되지 않음 (`Engage` 무반응)

- 체크리스트:
  - [ ] 세 트래커 모두 추적 상태 정상
  - [ ] MANUS 양손 캘리브레이션 로드됨
  - [ ] Quest head_pose 토픽 수신 중
  - [ ] `/teleop/active_owner` 가 비어 있거나 자기 자신
- 위 중 하나라도 실패하면 텔레옵 노드가 활성화를 거부합니다.

## MCAP 파일 크기가 비정상적으로 작음

- 녹화 시 토픽 화이트리스트가 잘못되었을 가능성
- `aidin_rby1_teleop/config/record.yaml` 검토

## HDF5 변환 후 이미지가 까만 프레임

- Quest 스트리밍이 한 번 끊겼다가 복구된 경우일 수 있음
- 변환기 옵션에 `--drop_blank_frames true` 추가, 또는 검증 단계에서 마스킹

## 학습이 수렴은 하는데 실로봇에서 동작이 이상함

- 분포 변동: 정규화 통계가 학습/배포 사이 달라졌는지 확인
- 좌표계 변환 누락: EE 회전 표현(quat ↔ 6D) 변환 일관성
- 학습 시 disengage 구간이 데이터에 섞여 들어가지 않았는지 확인
- Quest 카메라 자세가 학습 분포와 동일한지 확인

## 추론 노드가 토픽을 발행하지 않음

- `deploy_dir` 의 yaml 들과 학습 시 conf 의 토픽 이름 일치 여부 확인
- `ros2 topic info ...` 로 발행 측이 살아 있는지 확인
