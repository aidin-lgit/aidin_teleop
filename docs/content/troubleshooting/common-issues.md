## VIVE Tracker 가 녹색으로 연결되지 않음

- **원인 후보**: Lighthouse 시야 가림, 채널 충돌, 배터리 부족
- **조치**: 베이스 위치 재조정, 채널 재설정, 트래커 장치 페어링

## 원격제어 노드가 활성화되지 않음

- 체크리스트:
  - [ ] 세 트래커 모두 추적 상태 정상
  - [ ] MANUS 양손 캘리브레이션 로드됨
  - [ ] Quest head_pose 토픽 수신 중
- 위 중 하나라도 실패하면 텔레옵 노드가 활성화를 거부합니다.

## MCAP 파일 크기가 비정상적으로 작음

- 녹화 시 토픽 화이트리스트가 잘못되었을 가능성
- `aidin_rby1_teleop/config/record.yaml` 검토

## 추론 노드가 토픽을 발행하지 않음

- `deploy_dir` 의 yaml 들과 학습 시 conf 의 토픽 이름 일치 여부 확인
- `ros2 topic info ...` 로 발행 측이 살아 있는지 확인
