## 1. 통합 텔레옵 + 학습 파이프라인

원격제어부터 데이터 수집, 학습, 추론까지 단일 ROS2 워크스페이스 안에서 일관된 토픽 인터페이스로 동작합니다.

## 2. 자사 로봇 핸드 통합

RBY1 의 기본 그리퍼 대신 자사 **AIDIN Robot Hand** 를 부착하여 다지(多指) 매니퓰레이션이 가능합니다.

## 3. 캘리브레이션 최소화

허리에 부착된 트래커를 기준으로 로봇 `base_footprint` 와의 **고정 변환**을 사용하므로 별도의 트래커-로봇 캘리브레이션 절차가 필요 없습니다.

## 4. MCAP 기반 raw 기록

저지연으로 모든 토픽을 MCAP 으로 통째 기록하여 후처리 단계에서 자유롭게 HDF5 등 학습 포맷으로 변환할 수 있습니다.

## 5. 모델 호환 Data Loader

Diffusion Policy 외에 ACT, BC-RNN 등 임의의 모방학습 모델에서 동일한 HDF5 데이터를 사용할 수 있도록 일반화된 Data Loader 와 매핑 가이드를 제공합니다.
