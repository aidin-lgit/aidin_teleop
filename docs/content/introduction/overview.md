## End-to-End 학습·추론 파이프라인

원격제어로 사람이 수행한 시연을 데이터로 모아 정책을 학습하고, 학습된 정책을 같은 로봇에
배포해 자율로 동일 작업을 수행하게 하는 전체 흐름입니다. 각 단계는 다음 단계의 입력이 되는
**산출물**을 남깁니다.

```
원격제어 → MCAP(raw) → HDF5 데이터셋 → run_dir(체크포인트) → 실로봇 자율 추론
```

| 단계 | 수행 | 산출물 |
|---|---|---|
| 1. 원격제어 | 작업자가 HMD·글로브·트래커를 착용하고 로봇을 직접 조종 | 실시간 ROS2 토픽 (관절·포즈·이미지) |
| 2. 데이터 기록 | 작업 중 모든 토픽을 MCAP 으로 저장 (세션 → 에피소드) | `*.mcap` (raw 데이터) |
| 3. 데이터 변환 | MCAP 을 RoboMimic 스타일 공통 HDF5 로 변환 | `dataset.hdf5` (학습 데이터셋) |
| 4. 학습 | `e2e-train` 으로 Diffusion Policy 정책 학습 | `run_dir` (`ckpt/best.pt` + `stats.json`) |
| 5. 추론 | `e2e-infer` 로 체크포인트를 실로봇에 배포해 자율 작업 수행 | 로봇 관절 명령 (자율 동작) |

### 동일 인터페이스 공유

학습·텔레옵·추론이 **같은 ROS2 토픽 인터페이스**를 공유합니다. 추론 노드는 텔레옵 노드와
동일한 입력 토픽을 구독하고 동일한 명령 토픽을 발행하므로, 텔레옵 ↔ 자율 모드를 전환해도
다운스트림 컨트롤러는 변경 없이 그대로 동작합니다.

단계별 상세 절차는 [데이터 수집](../../data-collection/) · [학습](../../training/) · [추론](../../inference/)
챕터에서, 처음부터 끝까지 한 번에 따라 하는 흐름은 [튜토리얼](../../tutorial/)에서 확인하세요.
